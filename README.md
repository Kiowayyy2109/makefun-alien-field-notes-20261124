Entry for [Alien Field Notes](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000) on make.fun: a program that writes one alien field note from two days of observing Earth to `/output/entry.txt`.

> Field note, day 2: humans will not eat until their glowing rectangle has seen the food first; the rectangle appears to be the senior species.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: every run writes the same bytes. It needs no network and no secrets.
